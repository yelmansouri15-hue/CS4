# CS102 — Data Structures Library (aparcada / no obligatoria)

> [!warning] Cambio de decisión — 2026-10-09
> Este proyecto deja de ser un requisito de CS102. No hay que terminar todas las estructuras ni los milestones antiguos. CS103 comienza sin esperar a este proyecto.

## Qué se conserva

- Dynamic Array: implementado, probado y evaluado.
- Singly Linked List: implementado.
- Doubly Linked List: implementado.
- El repositorio sirve como historial de aprendizaje, no como un producto que sea necesario convertir en una biblioteca competitiva frente a las estructuras estándar.

## Motivo del cambio

La finalidad de CS4 es desarrollar capacidades transferibles y acercarse a áreas como ML, criptografía/ciberseguridad y desarrollo técnico. Una biblioteca general implementada por obligación tiene bajo retorno si no corresponde a un objetivo de aprendizaje actual. Las implementaciones se harán selectivamente para entender invariantes, algoritmos, complejidad o mecanismos internos.

## Uso futuro posible

- Volver a implementar un heap o un BST para comprender su invariante.
- Crear un grafo mínimo para estudiar BFS/DFS.
- Añadir `pytest` cuando se quiera practicar testing automatizado.
- Documentar una implementación concreta si aporta valor al aprendizaje.

Ninguna de estas tareas tiene fecha ni es obligatoria por ahora.

## Historial del plan sustituido

Los milestones M1–M5 (septiembre–noviembre de 2026), la ponderación de evaluación y el plan de un exit exam pertenecían al diseño anterior de CS102 y quedan **superseded**. No contabilizarlos como deadlines pendientes.
