# CS4 — Resources

## Principio

No convertir CS4 en una colección infinita de cursos, plataformas y certificados. Usar una fuente principal por unidad y una fuente secundaria para practicar o aclarar dudas.

## CS103 — fuentes candidatas a evaluar

- MIT OpenCourseWare — *Mathematics for Computer Science*: materiales de nivel universitario sobre lógica, demostraciones, inducción, grafos, conteo y probabilidad discreta.
- *Discrete Mathematics: An Open Introduction* (Oscar Levin): libro abierto para teoría, ejemplos y ejercicios.
- Recursos de ejercicios solo si incluyen problemas relevantes y soluciones o criterios para autoevaluación.

El chat inicial de CS103 debe comprobar enlaces, versiones y accesibilidad actuales, y asignar capítulos/secciones y ejercicios concretos. No asumir que hay que completar un curso entero de terceros.

## Recursos ya conocidos

- Open Data Structures — estructuras de datos, para consulta selectiva.
- Documentación de Python — APIs estándar (`dict`, `set`, `collections.deque`, `heapq`, `pytest`).
- LeetCode — práctica ocasional de resolución de problemas; no es sustituto de un curso de algoritmos.
- freeCodeCamp — práctica gratuita y proyectos guiados de programación.
- DataCamp — alternativa interactiva, con acceso gratuito limitado y funciones de pago.
- Hugging Face Learn — exploración de ML moderno cuando se hayan cubierto los fundamentos.
- TryHackMe — laboratorios autorizados para explorar ciberseguridad práctica, no un sustituto de criptografía matemática.

Revisar la vigencia de recursos externos antes de asignarlos y citar fuentes oficiales cuando se actualice esta nota.

## CS104 — Computer Systems I

- **Fuente principal prevista:** *Computer Systems: A Programmer's Perspective* (CSAPP).
- Alcance inicial documentado en el plan: representación binaria/hexadecimal, representación de datos, overflow, floating point, memoria, stack, heap, CPU, assembly, instrucciones, compilación, linking y caching.
- Posible proyecto: pequeño intérprete o máquina virtual, solo si aporta valor formativo y encaja en la carga.
- El nuevo chat debe verificar edición/secciones y recursos actuales antes de asignarlos.
