## Flujo de trabajo

1. Al abrir una nueva conversación de CS4, adjuntar esta bóveda comprimida y copiar el prompt pertinente.
2. Consultar `00_Master/MASTER_RECORD.md`, `04_Deadlines/DEADLINES.md` y el archivo del curso activo.
3. Cada bloque de aprendizaje debe definir objetivos observables, fuentes concretas, ejercicios independientes, soluciones escalonadas, evaluación y criterio de dominio.
4. Registrar errores y recuperaciones en la nota del curso, no crear archivos sin utilidad.
5. Actualizar transcript, matriz de competencias y calendario solo con resultados reales.
6. Al terminar un bloque, pedir un resumen portable de estado para poder cambiar de chat sin perder continuidad.

## Política de estudio

Primero intenta resolver sin ayuda; usa el chat para planificación, pistas graduadas, feedback y evaluación, no para sustituir el esfuerzo. No se exige terminar cursos externos ni coleccionar certificados. La evidencia principal es poder explicar, aplicar y resolver ejercicios nuevos de forma independiente.
